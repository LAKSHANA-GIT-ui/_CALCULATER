# 🧮 Calculator Web Application

A simple and interactive calculator web application developed using **HTML, CSS, and JavaScript**. The project provides a clean user interface and supports basic arithmetic operations through interactive buttons.

## 🚀 Features

- Addition, subtraction, multiplication, and division
- Interactive calculator buttons
- Clear and reset functionality
- Basic error handling
- Clean and user-friendly interface
- Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
_CALCULATER/
│
├── calculator/
│   ├── index.html
│   ├── style.css
│   └── script.js
│
└── README.md
````

## ▶️ How to Run

1. Clone this repository.
2. Open the `calculator` folder.
3. Open `index.html` in any web browser.
4. Start performing calculations.
